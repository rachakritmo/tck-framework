# TCK — Ticket Control Kit

Control layer for AI work.

TCK helps human + AI teams operate with structure, accountability, and quality control through tickets, workflow states, logs, and role-based execution.

## Why TCK?

AI can generate work quickly, but unmanaged AI creates chaos.

TCK adds:

- Clear ownership
- Structured execution
- QA checkpoints
- Full audit history
- Multi-agent coordination
- Obsidian-native visibility

## Built For

- AI-assisted software teams
- Internal operations teams
- Agencies using AI workers
- Builders running multiple AI agents
